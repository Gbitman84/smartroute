# SmartRoute – סידור מסלול משלוחים

https://gbitman84.github.io/smartroute/ · פאנל ניהול: https://gbitman84.github.io/smartroute-admin/

- נתונים ב-Firestore: `labUsers/{uid}` (ימים, משלוחים, הגדרות), `members`, `invites`, `refs`, `registrations`, `config`, `quota`.
- מנוע מסלול: בוחרים בכל בנייה (🧭 בנה מסלול) – 🆓 רגיל (OSRM), 🧠 חכם (Google Route Optimization) או ⚖️ גם וגם. אם Google לא זמין, עובר אוטומטית לחינמי (עם הודעה אדומה).
- פרויקט Firebase: `smartrun-gbit` (השם ההיסטורי של הפרויקט; SmartRun עצמו לא בשימוש ואין לו גישה לנתונים).

## איך זה עובד
- האתר שולח את העצירות (קואורדינטות בלבד) לפונקציית ענן `optimizeRoute` (europe-west1).
- הפונקציה פונה ל-Route Optimization API עם Service Account (אין מפתח בדפדפן), ומחזירה סדר + קו מסלול.
- מה נלקח בחשבון: עומסי תנועה לפי שעה, צד הכביש של כל כתובת (`sideOfRoad`), זמן עצירה לכל כתובת (ברירת מחדל 90 שניות, בהגדרות), פניות אסורות וכיווני תנועה.
- ☰ ← **📊 השוואת מנועים**: מריץ את Google ואת המנוע החינמי על העצירות הפעילות, ומציג ק״מ, זמן וסדר זה לצד זה. לא נשמר דבר.
- ⚙️ הגדרות: בחירת מנוע, זמן עצירה, ועומסי תנועה.

## הגנות עלות
- **Google:** עד 3 בקשות בדקה. מצבי batch ו-long-running חסומים (0).
- **בפונקציה:** עד 40 חישובים ו-1,500 משלוחים ביום (שעון ישראל). מעבר לזה, מעבר אוטומטי למנוע החינמי.
- **פונקציות:** כל חבר פעיל ב-SmartRoute, עם מגבלה יומית לפי תפקיד (פאנל הניהול ← ⚙️ הגדרות).
- **תקציב:** ₪20 לחודש, עם התראות ב-50% וב-100%.
- **מחיר:** 5,000 משלוחים בחודש בחינם, ואחר כך כ-$10 לכל 1,000.

## 📷 ייבוא מצילומי מסך (Claude Vision)
📥 ייבוא ← לשונית **📷 צילומים** (לשונית **📋 טקסט** נשארה כמו תמיד).
- בוחרים כמה צילומים מהגלריה; הסדר ברשימה = הסדר בטבלה (אפשר להזיז ▲▼).
- כל צילום עולה ל-Firebase Storage ונקרא **בבקשה נפרדת** ע״י פונקציית הענן `extractShipments` (3 במקביל). Claude מחזיר JSON מובנה.
- **אופן קריאה** (גם בהגדרות): 🧠 אוטומטי (ברירת מחדל) – Sonnet קורא את הצילום, ו-Opus קורא שוב בזום את שורות השם והכתובת של כל כרטיס; כל הבדל מסומן בצהוב. קריאה מלאה חוזרת ב-Opus רק כשיש בעיה במספרים · Sonnet בלבד · Opus בלבד.
- **בדיקת שמות:** שם שלא מוכר, כשאיות דומה (ב↔ח, ה↔א, ד↔ר…) כן מוכר, מסומן בצהוב עם הצעה (`js/names.js` + שמות שנלמדים מייבואים מאושרים).
- **🔁 קריאה כפולה**: כל צילום נקרא ע״י Sonnet וגם Opus, וכל הבדל מסומן. בערך פי 3 במחיר.
- **תצוגה מקדימה**: תא צהוב = לא ודאי / קריאות שונות / רחוב לא ברשימה הרשמית; אדום = מספר משלוח עם עברית/רווח (שאלה אחת לפני הייבוא). לחיצה על תא מסומן פותחת את הצילום על הכרטיס, עם תיקון במקום. עמודת 📷 = מאיזה צילום, ⓘ = מה כל מודל קרא ולפני ← אחרי (עם שחזור).
- **חוסרים ב-#** מוצגים עם הצילומים שמשני הצדדים; **➕ הוסף צילום** קורא רק את הצילום החדש וממזג.
- הצילומים ופרטי הייבוא נשמרים **14 יום** (✎ במשלוח ← "📷 מקור + פרטי ייבוא"), ואז נמחקים ע״י `cleanupImports`.
- ☰ ← **🧪 בדיקת מודלים**: מריץ Sonnet ו-Opus על אותם צילומים ומציג כל שדה שבו הם שונים. לא נשמר כלום.
- **עלות (נמדדה 30/09):** אוטומטי ~$0.033 לצילום (Sonnet $0.017 + זום $0.016) · Sonnet בלבד ~$0.017 · Opus בלבד ~$0.033. כל צילום באוטומטי = 2 קריאות במכסה היומית.

### הקמה חד-פעמית
1. https://console.anthropic.com ← הרשמה ← Billing (כרטיס + קרדיט, ולהגדיר מגבלת הוצאה חודשית) ← API Keys ← Create Key.
2. שמירת המפתח כסוד של Firebase (יבקש להדביק את המפתח):
   ```bash
   npx -y firebase-tools@latest functions:secrets:set ANTHROPIC_API_KEY --project smartrun-gbit
   ```
3. Firebase Console ← Build ← **Storage** ← Get started (פעם אחת).

## פריסה
```bash
npx -y firebase-tools@latest deploy --only functions,firestore:rules,storage --project smartrun-gbit
```
`firestore.rules` ו-`storage.rules` מנוהלים רק כאן. הם פותחים רק נתיבים של SmartRoute; כל השאר (כולל `users/*` ו-`access/*` הישנים של SmartRun) חסום לכל הלקוחות.
**לא לפרוס** מהתיקייה הישנה `SmartRun\SmartRun` – יש בה `firebase.json` ישן שידרוס את הכללים.
